# Инструкции для ИИ-агентов (Claude Code, Codex)

Это БиоВиз: платформа научной группы по микробиологии (элитная подготовка). Владелец пишет по-русски, отвечай по-русски.

## Главное правило

Материал на платформу добавляет владелец. Не добавляй лекции, разделы, модели, тренажёры, карточки, лабораторные работы и прочий контент без его прямой просьбы. Никаких разделов под ЕГЭ и ОГЭ.

## Правила

- Сайт статический, без сборки и без npm. Не добавляй фреймворки и бандлеры.
- Материал курса лежит в `content/`, список в `content/course.js`, инструкция в `content/README.md`. Код платформы в `bioviz/core/`.
- Всё рисуется внутри теневого DOM: используй `BVHOST.root`, `BV.$`, `BV.$$`, а для целей событий `BV_ET(e)`.
- Адреса страниц: `#/`, `#/l/<n>[/<раздел>]`, `#/labs[/<id>[/edit]]`, `#/me`. Роутер в `bioviz/core/app.js`, другие файлы добавляют страницы через `BV.app.add()`.
- Облако: `bioviz/x/cloud.js` ходит в функции `bv_*` Supabase. Права проверяются на сервере, в браузере ключ только публичный.
- ИИ-помощника на сайте нет (убран по просьбе владельца 2026-11-02). Вместо него `bioviz/core/prompt.js`: у выделенного текста кнопка «Создать промпт», которая копирует промпт в буфер обмена. Сайт сам к ИИ не обращается, не возвращай помощника без прямой просьбы.
- Лабораторные работы (`bioviz/core/labworks.js`) хранятся в облаке, коллекции `labworks` и `labfiles`, добавляет их руководитель на сайте. Панель руководителя в `bioviz/core/admin.js`.
- Никогда не коммить секретный код руководителя, сервисные ключи Supabase и ключ Anthropic.
- После правок: `node --check` для изменённых JS, локальный сервер `python3 -m http.server`, проверка на ширине телефона (390 px) и в тёмной теме.
- Перед push подними `BV_VER` в `index.html`, иначе браузеры участников возьмут старые скрипты из кеша.
- Биологические факты сверяй с учебниками (Нетрусов и Котова, Мадиган, Альбертс). Не выдумывай чисел.

## Трек к ШАДу (папка `shad/`)

Личный трекер подготовки к ШАД. Расписание вебов целиком в `shad/plan.json`, одна строка = один веб; правки плана делай там, не трогая `app.js`. Номера `n` уже пройденных вебов не меняй: по ним хранятся отметки. Подробности в `shad/README.md`. Трекер берёт `bioviz/x/cloud.js`, не переноси этот файл.

## Режим бамбука (папка `bamboo/`)

Личный дневник режима владельца: задачи, календарь, помодоро, привычки, чтение, тренировки, дневник, опыт и бамбук, который растёт с уровнем. Данные в коллекции `bamboo` (только код учителя), отметки ШАДа общие с `shad/`, план ШАДа читается из `shad/plan.json`. Правила опыта в `bamboo/js/core.js`. После правок подними `?v=` у изменённых файлов в `bamboo/index.html`. Подробности в `bamboo/README.md`.

## Фаги естественных наук (папка `phagi/`)

Платформа занятий с ученицами, перенесена из артефакта claude.ai. База в Supabase (функции `ph_*`, правила в таблице `ph_rules`), адаптер `phagi/cloud.js`. Подробности в `phagi/README.md`. Коды учениц в репозиторий не клади.

## Код для учёбы

Решения задач для ШАД (C++, Python, алгоритмы) в этот репозиторий не клади. Там владелец пишет код сам, ИИ только проверяет и объясняет ошибки.
