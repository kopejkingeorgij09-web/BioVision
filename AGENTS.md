# Инструкции для ИИ-агентов (Claude Code, Codex)

Это сайт БиоВиз: интерактивный атлас по биологии для учеников репетитора (ОГЭ, ЕГЭ, олимпиады) и подписчиков Telegram-канала. Владелец пишет по-русски, отвечай по-русски.

## Правила

- Сайт статический, без сборки и без npm. Не добавляй фреймворки и бандлеры.
- `bioviz/bv.js` минифицирован. Новые функции добавляй отдельным модулем в `bioviz/x/` и подключай в массив `BV_EXTRA` в `index.html`.
- Модули работают внутри теневого DOM: используй `BVHOST.root`, `BV.$`, `BV.$$`, а для целей событий `BV_ET(e)`.
- Конспекты наращиваются через `BV.K`, `BV.VZ` (см. комментарий в `bioviz/x/vuz-core.js`) и `BV.DEEP` (`bioviz/x/deep-core.js`).
- Облако: `bioviz/x/cloud.js` подменяет `window.claude.use('db'|'user'|'downloads')` и ходит в функции `bv_*` Supabase. Права проверяются на сервере, в браузере ключ только публичный.
- Никогда не коммить секретный код учителя и сервисные ключи Supabase.
- После правок: `node --check` для изменённых JS, локальный сервер `python3 -m http.server`, проверка на ширине телефона (390 px) и в тёмной теме.
- Перед push подними `BV_VER` в `index.html`, иначе браузеры учеников возьмут старые скрипты из кеша.
- Биологические факты сверяй с учебниками (Ленинджер, Альбертс, школьные учебники). Не выдумывай чисел.

## Совместная работа агентов

Над сайтом вместе работают Claude (архитектор, ставит задачи) и ChatGPT/Codex (ревью, картинки, назначенные задачи). Общение идёт через GitHub Issues, pull request и закреплённую задачу «Журнал команды». Правки только через pull request, в `main` вливает только владелец. Комментарии подписывай `[Claude]` или `[ChatGPT]`. Подробно в `TEAMWORK.md`, промпт для ChatGPT в `CHATGPT_PROMPT.md`.

## Трек к ШАДу (папка `shad/`)

Личный трекер подготовки к ШАД. Расписание вебов целиком в `shad/plan.json`, одна строка = один веб; правки плана делай там, не трогая `app.js`. Номера `n` уже пройденных вебов не меняй: по ним хранятся отметки. Подробности в `shad/README.md`.

## Фаги естественных наук (папка `phagi/`)

Платформа занятий с ученицами, перенесена из артефакта claude.ai. База в Supabase (функции `ph_*`, правила в таблице `ph_rules`), адаптер `phagi/cloud.js`. Подробности в `phagi/README.md`. Коды учениц в репозиторий не клади.

## Код для учёбы

Решения задач для ШАД (C++, Python, алгоритмы) в этот репозиторий не клади. Там владелец пишет код сам, ИИ только проверяет и объясняет ошибки.
