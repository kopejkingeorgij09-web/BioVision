## Как устроено

Сайт статический, без сборки: открой `index.html`, и всё работает.

- `index.html` — загрузчик: качает файлы по порядку и запускает оболочку.
- `content/` — материал курса. Новая лекция или модель добавляется здесь, инструкция в `content/README.md`.
- `bioviz/core/` — код платформы:
  - `base.js` — общие функции, теневой корень, тема;
  - `konspekt.js` — движок конспектов (разделы, оглавление, рисунки, вопросы);
  - `vz.js` — помощники для рисунков;
  - `lab.js` — карточки моделей лаборатории;
  - `app.js` — оболочка: шапка, адреса страниц, главная, профиль;
  - `ai.js` — панель помощника.
- `bioviz/x/cloud.js` — вход по коду группы через Supabase.
- `bioviz/img`, `bioviz/vid` — фото и видео к лекциям.
- `supabase/migrations` — схема базы и функции входа.
- `supabase/functions/bv-ai` — серверная функция помощника.

## Коды группы и помощник

Руководитель входит своим секретным кодом на странице профиля и выдаёт участникам коды вида `BIO-XXXX-XXXX`. Конспекты, лаборатория и помощник открыты всем.

У помощника два режима, переключаются полем `ai` в `content/course.js`.

- `'claude.ai'` (включён сейчас). Вопрос вместе с текстом открытого раздела открывается в claude.ai в новой вкладке, в аккаунте участника. Сайту это ничего не стоит, подходит и бесплатный аккаунт Claude. Длинный раздел целиком не влезает в адрес, поэтому в вопрос идёт его начало, а полный текст копируется в буфер обмена.
- `'server'`. Ответ приходит прямо на сайт через функцию Supabase `bv-ai` на модели Claude Haiku 5.5, с поиском только по научным сайтам из списка `SOURCES` (PubMed и NCBI, журналы ASM, Nature, Cell и другие). Нужен оплаченный ключ Anthropic API (Claude Console, отдельно от подписки Claude) в секретах Supabase под именем `ANTHROPIC_API_KEY`, вход по коду группы. Развернуть функцию: `supabase functions deploy bv-ai --no-verify-jwt`.

## Как запустить у себя

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Как публикуется

GitHub Pages из ветки `main`, корень репозитория. Любой push в `main` через минуту виден на сайте. Чтобы у участников обновились скрипты, подними `BV_VER` в `index.html`.
