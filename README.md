# БиоВиз

Платформа научной группы по микробиологии: конспекты лекций с интерактивными рисунками и журнал лабораторных работ. Выделенный фрагмент текста превращается в готовый промпт для любого ИИ.

Сайт: https://kopejkingeorgij09-web.github.io/BioVision/

## Как устроено

Сайт статический, без сборки: открой `index.html`, и всё работает.

- `index.html` — загрузчик: качает файлы по порядку и запускает оболочку.
- `content/` — материал курса. Новая лекция добавляется здесь, инструкция в `content/README.md`.
- `bioviz/core/` — код платформы:
  - `base.js` — общие функции, теневой корень, тема;
  - `konspekt.js` — движок конспектов (разделы, оглавление, рисунки, вопросы);
  - `vz.js` — помощники для рисунков;
  - `app.js` — оболочка: шапка, адреса страниц, главная, профиль, объявление и скрытые лекции;
  - `prompt.js` — кнопка «Создать промпт» у выделенного текста;
  - `labworks.js` — лабораторные работы: список, страница работы, редактор с фотографиями;
  - `admin.js` — панель руководителя на `#/me`.
- `bioviz/x/cloud.js` — вход по коду группы через Supabase.
- `bioviz/img`, `bioviz/vid` — фото и видео к лекциям.
- `supabase/migrations` — схема базы и функции входа.

## Адреса

| Адрес | Что открывает |
|---|---|
| `#/` | главная курса |
| `#/l/1` | лекция 1 |
| `#/l/1/mb4` | лекция 1, раздел 4 |
| `#/labs` | лабораторные работы |
| `#/labs/<id>` | одна работа; `#/labs/<id>/edit` и `#/labs/new` — редактор руководителя |
| `#/me` | вход; у руководителя панель управления |

Кнопка «Назад» в браузере работает, ссылку на раздел можно отправить в чат группы. Старые адреса `#bact`, `#microlab` и `#/lab/...` перенаправляются.

## Коды группы и панель руководителя

Руководитель входит своим секретным кодом на странице профиля. Там же панель управления:

- объявление на главной;
- скрытие лекций, пока они готовятся;
- лабораторные работы (добавляются и правятся прямо на сайте, с фотографиями);
- участники: выдать код вида `BIO-XXXX-XXXX`, переименовать, скопировать, удалить, посмотреть, какие разделы лекций прочитаны;
- резервная копия всех данных одним файлом JSON.

Конспекты и лабораторные работы открыты всем без кода. С кодом участника прочитанные разделы уходят в облако, и их видит руководитель.

Данные лежат в Supabase в таблице `bv_docs`: `labworks` (работы), `labfiles` (фото, по документу на снимок), `site` (объявление и скрытые лекции), `students` (прогресс участников). Права проверяют функции `bv_*`, миграция `supabase/migrations/20261102_labworks_admin.sql`.

## Создать промпт

Если выделить фрагмент текста в конспекте или лабораторной работе, рядом появляется кнопка «Создать промпт». Она копирует в буфер обмена готовый запрос: сам фрагмент, откуда он, текст вокруг и требования к ответу (полное объяснение, проверка точности, ссылки на учебники и статьи с DOI или PMID, без выдуманных источников). Промпт вставляется в любой ИИ-чат. Сайт сам ничего не отправляет.

## Как запустить у себя

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Как публикуется

GitHub Pages из ветки `main`, корень репозитория. Любой push в `main` через минуту виден на сайте. Чтобы у участников обновились скрипты, подними `BV_VER` в `index.html`.
