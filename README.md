# БиоВиз

Интерактивный атлас по биологии: экскурсия по клетке, виртуальный микроскоп, анимации процессов, конспекты с визуализациями, тренажёр на сотни вопросов, карточки с интервальным повторением, разделы для элитной группы (микробиологическая лаборатория, биоинформатика, кворум-сенсинг).

Сайт: https://kopejkingeorgij09-web.github.io/BioVision/

## Как устроено

Сайт статический, без сборки: открой `index.html`, и всё работает.

- `index.html` — оболочка: шапка, cookie-баннер, загрузчик модулей.
- `bioviz/bv.js` — основной код (минифицирован, правится редко).
- `bioviz/x/*.js` — модули и дополнения. Почти все правки идут сюда.
- `bioviz/x/cloud.js` — облако учеников на Supabase и вход по коду.
- `bioviz/img`, `bioviz/vid` — картинки и видео.
- `supabase/migrations` — схема базы и функции входа.

## Облако учеников

Прогресс хранится в Supabase (проект `bioviz`). Вход по коду:

- учитель входит своим секретным кодом в разделе «Профиль и прогресс» и выдаёт ученикам коды вида `BIO-XXXX-XXXX`;
- ученик вводит код, и его ошибки и статистика сохраняются в облаке и видны учителю в журнале.

Секретный код учителя в репозитории не хранится, в базе лежит только его хеш.

## Как запустить у себя

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Как публикуется

GitHub Pages из ветки `main`, корень репозитория. Любой push в `main` через минуту виден на сайте. Чтобы у учеников обновились скрипты, подними `BV_VER` в `index.html`.
