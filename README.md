# БиоВиз

Платформа научной группы по микробиологии: конспекты лекций с интерактивными рисунками и журнал лабораторных работ. Выделенный фрагмент текста превращается в готовый промпт для любого ИИ.

Сайт: https://kopejkingeorgij09-web.github.io/BioVision/

## Как устроено

Сайт статический, без сборки: открой `index.html`, и всё работает.

- `index.html` — загрузчик: качает файлы по порядку и запускает оболочку.
- `content/` — материал курса. Новая лекция добавляется здесь, инструкция в `content/README.md`.
- `bioviz/core/` — код платформы:
  - `base.js` — общие функции, теневой корень, тема;
  - `konspekt.js` — движок конспектов (разделы, оглавление, рисунки, вопросы);
  - `vz.js` — помощники для рисунков;
  - `app.js` — оболочка: шапка, адреса страниц, главная, профиль, объявление и скрытые лекции;
  - `prompt.js` — кнопка «Создать промпт» у выделенного текста;
  - `labworks.js` — лабораторные работы: список, страница работы, редактор с фотографиями;
  - `admin.js` — панель руководителя на `#/me`; `activity.js` — счётчики использования и отчёт.
  - `reading.js`, `reading.css` — «Фундаментальное чтиво»: локальная полка PDF, адаптивный Альбертс и банк заданий. Источник и проверки точности описаны в `content/reading/README.md`.
- `bioviz/x/cloud.js` — вход по коду группы через Supabase.
- `bioviz/img`, `bioviz/vid` — фото и видео к лекциям.
- `supabase/migrations` — схема базы и функции входа.

## Адреса

| Адрес | Что открывает |
|---|---|
| `#/` | главная курса |
| `#/l/1` | лекция 1 |
| `#/l/1/mb4` | лекция 1, раздел 4 |
| `#/labs` | лабораторные работы |
| `#/labs/<id>` | одна работа; `#/labs/<id>/edit` и `#/labs/new` — редактор руководителя |
| `#/me` | вход; у руководителя панель управления |
| `#/reading` | фундаментальное чтиво: библиотека учебников |
| `#/reading/alberts/1-intro` | Альбертс, том 1, адаптивное чтение |
| `#/reading/practice` | банк заданий к Альбертсу |

Кнопка «Назад» в браузере работает, ссылку на раздел можно отправить в чат группы. Старые адреса `#bact`, `#microlab` и `#/lab/...` перенаправляются.

## Личный код и управление

Посетитель сам создаёт личный код в профиле (`#/me`) или в «Чтиве». Один код синхронизирует место чтения, закладки, ответы, самооценку, настройки читалки и отметки лекций между устройствами. PDF остаются локально. Подробности: `tools/PERSONAL_LEARNING.md`.

Руководитель входит секретным кодом через «Вход руководителя» в профиле. В управлении доступны объявление, скрытие лекций, лабы с фотографиями, резервная копия и статистика платформы за 7, 30 или 90 дней. Панели выдачи кодов нет; ранее выданные коды продолжают работать.

Статистика показывает посещения разделов, использование функций, читаемые лекции и микротемы, активное время и темп по посетителям. Устройства с одним личным кодом объединяются в профиль; без кода гость определяется в пределах браузера. Личные коды и тексты ответов в отчёт не попадают. Сбор начинается после обновления сайта, предыдущая история не восстанавливается. Устройство руководителя исключено. Устройство и профиль — технические идентификаторы, не подтверждённые личности.

Настройки и лабы лежат в `bv_docs`, личные записи — в закрытой схеме `bv_personal`, счётчики использования — в закрытой схеме `bv_usage`. Доступ проверяют серверные функции; отчёт `bv_activity_report` доступен только с кодом руководителя. Подробности и проверки: `tools/VISITOR_ACTIVITY.md`.

## Создать промпт

Если выделить фрагмент текста в конспекте или лабораторной работе, рядом появляется кнопка «Создать промпт». Она копирует в буфер обмена готовый запрос: сам фрагмент, откуда он, текст вокруг и требования к ответу (полное объяснение, проверка точности, ссылки на учебники и статьи с DOI или PMID, без выдуманных источников). Промпт вставляется в любой ИИ-чат. Сайт сам ничего не отправляет.

## Как запустить у себя

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Как публикуется

GitHub Pages из ветки `main`, корень репозитория. Любой push в `main` через минуту виден на сайте. Чтобы у участников обновились скрипты, подними `BV_VER` в `index.html`.
