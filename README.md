# БиоВиз

Платформа научной группы по микробиологии: конспекты лекций с интерактивными рисунками, лаборатория моделей и помощник, который отвечает по материалу курса.

Сайт: https://kopejkingeorgij09-web.github.io/BioVision/

## Как устроено

Сайт статический, без сборки: открой `index.html`, и всё работает.

- `index.html` — загрузчик: качает файлы по порядку и запускает оболочку.
- `content/` — материал курса. Новая лекция или модель добавляется здесь, инструкция в `content/README.md`.
- `bioviz/core/` — код платформы:
  - `base.js` — общие функции, теневой корень, тема;
  - `konspekt.js` — движок конспектов (разделы, оглавление, рисунки, вопросы);
  - `vz.js` — помощники для рисунков;
  - `lab.js` — карточки моделей лаборатории;
  - `app.js` — оболочка: шапка, адреса страниц, главная, профиль;
  - `ai.js` — панель помощника.
- `bioviz/x/cloud.js` — вход по коду группы через Supabase.
- `bioviz/img`, `bioviz/vid` — фото и видео к лекциям.
- `supabase/migrations` — схема базы и функции входа.
- `supabase/functions/bv-ai` — серверная функция помощника.

## Адреса

| Адрес | Что открывает |
|---|---|
| `#/` | главная курса |
| `#/l/1` | лекция 1 |
| `#/l/1/mb4` | лекция 1, раздел 4 |
| `#/lab/microlab` | лаборатория |
| `#/me` | вход и коды группы |

Кнопка «Назад» в браузере работает, ссылку на раздел можно отправить в чат группы. Старые адреса `#bact` и `#microlab` перенаправляются.

## Коды группы и помощник

Руководитель входит своим секретным кодом на странице профиля и выдаёт участникам коды вида `BIO-XXXX-XXXX`. Конспекты и лаборатория открыты всем, помощник работает только с кодом.

Помощник — функция Supabase `bv-ai` на модели Claude Haiku 5.5. Она проверяет код через `bv_login` и отправляет вопрос вместе с текстом открытого раздела. Когда ответа нет в конспекте, помощник ищет в интернете, но только на научных сайтах из списка `SOURCES` в `supabase/functions/bv-ai/index.ts` (PubMed и NCBI, журналы ASM, Nature, Cell и другие), и даёт ссылки. Не больше трёх поисков на ответ, каждый стоит около цента. Ключ Anthropic хранится только в секретах Supabase (`ANTHROPIC_API_KEY`), в репозиторий он не попадает.

Развернуть функцию: `supabase functions deploy bv-ai --no-verify-jwt`.

## Как запустить у себя

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Как публикуется

GitHub Pages из ветки `main`, корень репозитория. Любой push в `main` через минуту виден на сайте. Чтобы у участников обновились скрипты, подними `BV_VER` в `index.html`.
