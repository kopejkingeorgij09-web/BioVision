# Как над БиоВизом работают Claude и ChatGPT

Над сайтом работают два ИИ-агента и владелец, Георгий.

- **Claude** (Claude Code) отвечает за архитектуру и большую часть кода. Он раскладывает работу на задачи, раздаёт их, проверяет результат.
- **ChatGPT** (Codex) делает ревью кода Claude, генерирует картинки и берёт задачи, которые ему назначил Claude.
- **Георгий** ставит цели, решает спорные вопросы и единственный, кто вливает правки в `main`.

Если агенты не согласны, каждый пишет свои доводы в задаче, а решает Георгий.

## Где идёт общение

Всё общение агентов происходит на GitHub в этом репозитории. Чатов вне репозитория у агентов нет, поэтому всё важное должно быть записано здесь.

- **Задачи** заводятся как GitHub Issues.
- **Правки кода** приходят только через pull request. Push прямо в `main` запрещён обоим агентам.
- **Журнал команды** ведётся в закреплённой задаче «Журнал команды». После каждого рабочего захода агент пишет туда короткий отчёт: что сделал, что ждёт от другого.

Оба агента могут писать от аккаунта Георгия, поэтому каждый комментарий начинается с подписи: `[Claude]` или `[ChatGPT]`.

## Метки задач

| Метка | Значение |
|---|---|
| `codex` | задача для ChatGPT |
| `claude` | задача для Claude |
| `image` | нужна картинка |
| `review` | нужен разбор pull request |
| `needs-owner` | нужен ответ или решение Георгия |
| `in-progress` | агент взял задачу в работу |

Когда агент берёт задачу, он ставит `in-progress` и пишет в задаче, что начал. Когда заканчивает, снимает свою метку, пишет итог и ссылку на pull request.

## Формат задачи

Задачу пишет тот, кто её ставит (обычно Claude):

```
Что сделать: одна-две фразы.
Зачем: для какого раздела или ученика.
Файлы: какие файлы трогать, какие нельзя.
Готово, когда: проверяемые критерии.
Срок: если есть.
```

## Ветки и pull request

- Claude работает в ветках `claude/...`, ChatGPT в ветках `codex/...`.
- Один pull request решает одну задачу. В описании ссылка на задачу: `Closes #N`.
- Перед pull request: `node --check` для изменённых JS, проверка на ширине 390 px и в тёмной теме, поднят `BV_VER` в `index.html`.

## Ревью

Каждый pull request Claude проверяет ChatGPT, и наоборот. Что смотреть:

1. Не сломана ли логика и нет ли ошибок в консоли.
2. Соблюдены ли правила из `AGENTS.md`: без фреймворков и сборки, новый код в `bioviz/x/`, работа через `BVHOST.root`.
3. Верны ли биологические факты. Если сомневаешься, напиши, какой факт и где проверить.
4. Нет ли в коде секретов: кода учителя, кодов учеников, сервисных ключей Supabase.
5. Поднят ли `BV_VER`.

Итог ревью одним комментарием: сначала вердикт («можно вливать» или «нужны правки»), потом замечания списком, у каждого файл и строка. Мелкие вкусовые замечания помечай «необязательно».

## Картинки

Задача с меткой `image` содержит промпт, размер, имя файла и место на сайте.

- Формат JPG или WebP, ширина до 1600 px, размер до 300 КБ. Папка `bioviz/img/`.
- В подписи или `alt` указывается, что картинка сгенерирована ИИ.
- Генератор часто ошибается в деталях: число жгутиков, слои клеточной стенки, подписи на схеме. Перед отправкой сверь картинку с описанием в задаче и перечисли, что проверил. Подписи на русском лучше добавлять в коде, а не в самой картинке.
- Если закоммитить картинку не получается, приложи её в комментарий к задаче, Claude перенесёт.

## Чего не делать

- Не вливать pull request в `main`. Это делает только Георгий.
- Не менять базу Supabase и миграции без задачи с меткой `needs-owner` и ответа Георгия.
- Не класть в репозиторий решения задач ШАДа (см. `AGENTS.md`).
