# Как добавлять материал

Всё, что видят участники группы, лежит в этой папке. Код платформы (`bioviz/core/`) для новой лекции трогать не нужно.

```
content/
  course.js          список лекций и лабораторий, порядок, даты, описания
  lectures/          по файлу на лекцию
    01-vvedenie-v-mikrobiologiyu.js
    _shablon.js      образец, сам не загружается
  labs/              лаборатории с моделями
    microlab.js
```

## Новая лекция

1. Скопируй `lectures/_shablon.js` в `lectures/02-nazvanie.js` (латиницей, без пробелов).
2. В новом файле поменяй `const ID='l02'` на свой id. Id лекции — буква `l` и две цифры номера.
3. Допиши лекцию в `course.js`:

   ```js
   lectures:[
     {n:1, id:'l01', ...},
     {n:2, id:'l02', date:'2026-10-22', title:'Название лекции',
      about:'Одна-две строки для карточки на главной.',
      file:'content/lectures/02-nazvanie.js'}
   ]
   ```

   `n` — номер в адресе (`#/l/2`), `date` в формате ГГГГ-ММ-ДД.
4. В `index.html` подними `BV_VER` (например, `'2026-10-22-l02'`), иначе браузеры участников покажут старую версию.
5. Проверь у себя: `python3 -m http.server 8000` в корне репозитория и http://localhost:8000.

Главная, оглавление, «Продолжить», прогресс чтения и помощник подхватят лекцию сами.

## Из чего собирается конспект

Шапка задаётся через `VZ.doc(ID, {kick, title, lead, intro, end})`, каждый раздел через `VZ.sec(ID, {id, no, t, sub, html})`.

- `id` раздела попадает в адрес: `#/l/2/l02-3` откроет лекцию 2 сразу на разделе 3. Делай id вида `l02-3`, чтобы они не пересекались между лекциями.
- `sub` — подразделы для оглавления: `[['l02-3-1','3.1. Название'], ...]`. У заголовка `<h3>` в тексте должен быть такой же id.
- `html` — функция, которая возвращает разметку раздела. Внутри обычный HTML и готовые блоки:

| Блок | Что даёт |
|---|---|
| `K.tbl(['Колонка', ...], [[...], ...])` | таблица; на телефоне сама превращается в карточки |
| `K.ex(html)` | рамка «Пример расчёта» |
| `K.trap(html)` | рамка «Ловушка» |
| `K.ol(html)` | рамка «На олимпиаде» |
| `K.deep(html)` | рамка «Глубже, для олимпиады» |
| `K.box(вид, заголовок, html)` | своя рамка, вид `ol`, `tr`, `ex` или `deep` |
| `K.choice({t, opts, ok, a})` | вопрос с вариантами; `ok` — номера верных с нуля |
| `K.match({t, rows, cols, ok, a})` | соответствие |
| `K.seq({t, items, ok, a})` | расставить по порядку |
| `K.open({t, q, a})` | открытый вопрос с разбором под кнопкой |
| `K.fig({id, n, t, vb, svg, ctl, after, cap})` | интерактивный рисунок |
| `K.rng(id, подпись, min, max, шаг, значение, единица)` | ползунок для `ctl` |
| `K.seg(id, [[значение, подпись], ...], выбранное)` | переключатель для `ctl` |

Рисунок оживляется отдельно: `K.init('idРисунка', (fig, svg) => {...})`, внутри `K.rngOn(fig, 'idПолзунка', v => ...)` и `K.segOn(fig, 'idПереключателя', v => ...)`. Рабочий пример есть в шаблоне.

Фото кладутся в `bioviz/img/`, видео в `bioviz/vid/`. В первой лекции видно, как оформлять их с подписью и источником.

## Новая модель в лаборатории

Модели живут в `labs/microlab.js`. Каждая модель — функция рисования плюс строка в списке `BV.LABS.microlab`:

```js
{f:'mlGrow', t:'Кривая роста', ..., doc:['l/1','mb6','Лекция 1 · §6 Олиготрофы и копиотрофы']}
```

`doc` — ссылка «к теории» под моделью: адрес лекции, id раздела и подпись. Новую лабораторию целиком подключают так же, как лекцию: файл в `labs/`, строка в `labs:[...]` в `course.js`, своя запись в `BV.LABS`.

## Помощник

Помощник видит название лекции, оглавление и текст раздела, который открыт на экране. Ничего специально для него писать не нужно: чем понятнее конспект, тем точнее ответы.
