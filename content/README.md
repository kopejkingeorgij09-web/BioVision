# Как добавлять материал

Всё, что видят участники группы, лежит в этой папке. Код платформы (`bioviz/core/`) для новой лекции трогать не нужно.

```
content/
  course.js          список лекций, порядок, даты, описания
  lectures/          по файлу на лекцию
    01-vvedenie-v-mikrobiologiyu.js
    _shablon.js      образец, сам не загружается
```

## Новая лекция

1. Скопируй `lectures/_shablon.js` в `lectures/02-nazvanie.js` (латиницей, без пробелов).
2. В новом файле поменяй `const ID='l02'` на свой id. Id лекции — буква `l` и две цифры номера.
3. Допиши лекцию в `course.js`:

   ```js
   lectures:[
     {n:1, id:'l01', ...},
     {n:2, id:'l02', date:'2026-10-22', title:'Название лекции',
      about:'Одна-две строки для карточки на главной.',
      file:'content/lectures/02-nazvanie.js'}
   ]
   ```

   `n` — номер в адресе (`#/l/2`), `date` в формате ГГГГ-ММ-ДД.
4. В `index.html` подними `BV_VER` (например, `'2026-10-22-l02'`), иначе браузеры участников покажут старую версию.
5. Проверь у себя: `python3 -m http.server 8000` в корне репозитория и http://localhost:8000.

Главная, оглавление, «Продолжить», прогресс чтения и кнопка «Создать промпт» подхватят лекцию сами.

## Из чего собирается конспект

Шапка задаётся через `VZ.doc(ID, {kick, title, lead, intro, end})`, каждый раздел через `VZ.sec(ID, {id, no, t, sub, html})`.

- `id` раздела попадает в адрес: `#/l/2/l02-3` откроет лекцию 2 сразу на разделе 3. Делай id вида `l02-3`, чтобы они не пересекались между лекциями.
- `sub` — подразделы для оглавления: `[['l02-3-1','3.1. Название'], ...]`. У заголовка `<h3>` в тексте должен быть такой же id.
- `html` — функция, которая возвращает разметку раздела. Внутри обычный HTML и готовые блоки:

| Блок | Что даёт |
|---|---|
| `K.tbl(['Колонка', ...], [[...], ...])` | таблица; на телефоне сама превращается в карточки |
| `K.ex(html)` | рамка «Пример расчёта» |
| `K.trap(html)` | рамка «Ловушка» |
| `K.ol(html)` | рамка «На олимпиаде» |
| `K.deep(html)` | рамка «Глубже, для олимпиады» |
| `K.box(вид, заголовок, html)` | своя рамка, вид `ol`, `tr`, `ex` или `deep` |
| `K.choice({t, opts, ok, a})` | вопрос с вариантами; `ok` — номера верных с нуля |
| `K.match({t, rows, cols, ok, a})` | соответствие |
| `K.seq({t, items, ok, a})` | расставить по порядку |
| `K.open({t, q, a})` | открытый вопрос с разбором под кнопкой |
| `K.fig({id, n, t, vb, svg, ctl, after, cap})` | интерактивный рисунок |
| `K.rng(id, подпись, min, max, шаг, значение, единица)` | ползунок для `ctl` |
| `K.seg(id, [[значение, подпись], ...], выбранное)` | переключатель для `ctl` |
| `K.mol({id, n, pdb, t, cap, parts})` | вращающаяся 3D-модель из RCSB PDB, см. ниже |

Рисунок оживляется отдельно: `K.init('idРисунка', (fig, svg) => {...})`, внутри `K.rngOn(fig, 'idПолзунка', v => ...)` и `K.segOn(fig, 'idПереключателя', v => ...)`. Рабочий пример есть в шаблоне.

Врезка с заголовком, который начинается со слова «Мостик» (например, «Мостик от школьного курса»), на сайте свёрнута в таблетку и раскрывается по клику. Свернуть другую врезку так же можно, добавив ей класс `k-fold`: `<div class="k-box k-vuz k-fold"><b>Заголовок</b>…</div>`.

### Рисунок справа от текста и подсветка при прокрутке

На широком экране (ноутбук) все рисунки `K.fig` уходят в колонку справа, а в тексте на их месте остаётся строка «Рис. N». Справа всегда стоит рисунок того места, которое сейчас читают. На телефоне рисунок остаётся в тексте; когда он уходит за верхний край, появляется чип «Рис. N», который открывает рисунок поверх текста. Для этого ничего делать не нужно.

Чтобы рисунок менялся вместе с текстом, поставь абзацу (`<p>`, `<li>`, `<h4>`) атрибут `data-hl`. Когда абзац дойдёт до середины экрана, рисунок перейдёт в указанное состояние, а слева от абзаца загорится зелёная черта. Несколько действий пишутся через `;`:

| Запись | Что происходит |
|---|---|
| `data-hl="mbMotorS=pos"` | переключатель или ползунок с id `mbMotorS` получает значение `pos` |
| `data-hl="mbMotor@[data-p=mot]"` | нажимается деталь рисунка `mbMotor`, найденная по CSS-селектору |
| `data-hl="mbChain#g2"` | у рисунка `mbChain` подсвечиваются элементы с `data-k="g2"`, остальные бледнеют |
| `data-hl="mbChain"` | рисунок просто показывается, подсветка снимается |

Пример из лекции 1: `<li data-hl="mbMotorS=neg; mbMotor@[data-p=MS]"><b>Базальное тело</b> — …</li>`. Внутри `data-hl` кавычки только одинарные: `mbSize@[data-k='9']`. Метка привязывает рисунок только в пределах своего раздела (`VZ.sec`); в разделе без рисунков справа появляется список всех рисунков лекции.

### 3D-модели белков и нуклеиновых кислот

`K.mol` показывает структуру из банка RCSB PDB по её четырёхзначному ID. Модель загружается, когда читатель доходит до неё, и медленно вращается, пока видна на экране. Подпись под моделью сайт собирает сам из данных RCSB: ID, организм, метод, разрешение и статья с DOI. Так что в `cap` пиши только объяснение, без источника.

```js
K.mol({id:'ribo', n:'1.1', pdb:'4YBB', t:'Рибосома 70S кишечной палочки',
  cap:'Что видно на модели и на что смотреть.',
  parts:[{chain:'AA', name:'16S рРНК', color:'rna2'},
         {chain:'CA CB', name:'23S и 5S рРНК', color:'rna'}]})
```

- `parts` — части модели для подписи-легенды. `chain` перечисляет цепи через пробел, как они записаны на странице структуры в RCSB (буквы после `auth`). Цепи, которых нет ни в одной части, не рисуются; так из кристалла с двумя рибосомами показана одна. Без `parts` сайт раскрасит цепи сам по типу: белок, РНК, ДНК.
- Цвета: `protein`, `protein2`, `protein3` (зелёные), `rna`, `rna2` (терракотовые), `dna`, `dna2` (синие), `lig` (золотой), `violet`. Тёмная тема подбирает свои оттенки.
- Нажатие на часть в легенде выделяет её, остальные бледнеют. Из текста то же делает `data-hl="ribo#AA"` (цепь) или `data-hl="ribo#1"` (номер части с нуля).
- Структуры больше 45 тысяч атомов грузятся только по кнопке «Показать 3D-модель»: это несколько мегабайт.
- ID перед публикацией проверяй на rcsb.org: организм, метод и статья должны совпадать с тем, о чём текст.

Фото кладутся в `bioviz/img/`, видео в `bioviz/vid/`. В первой лекции видно, как оформлять их с подписью и источником.

## Лабораторные работы

Работы в эту папку не кладутся. Руководитель добавляет их на сайте: «Лабораторные работы» → «Новая работа» (или панель на странице профиля). В работе есть номер, дата, название, цель, оборудование и материалы, ход работы, результаты с фотографиями и выводы. Пока стоит галочка «Черновик», участники работу не видят.

В тексте работают абзацы через пустую строку, списки «- » и «1. », **жирный**, ссылки и таблицы строками вида `| столбец | столбец |`.

## Создать промпт

Выделенный в конспекте фрагмент можно превратить в промпт для любого ИИ кнопкой «Создать промпт». В промпт уходят фрагмент, название лекции и раздела и текст раздела вокруг, поэтому чем понятнее написан конспект, тем точнее ответ.

## Словарь и карточки терминов

Если в лекции есть словарь (список `dt`/`dd`, не меньше пяти терминов), сайт сам подчёркивает эти термины в тексте и показывает карточку с определением. Английское название и учебник со страницей для карточки задаются в файле лекции:

```js
(BV.termX=BV.termX||{}).l01={'КОЕ':{en:'CFU, colony-forming unit',src:'Hogg, Essential Microbiology, 2005, с. 92'}};
```

Ключ совпадает с термином в словаре. Страницу проверяй по самой книге, опись учебников лежит в папке проекта `textbooks/README.md`.
