# Поля

«Поля» — заметки в папках, тетради с вертикальной прокруткой, бесконечные доски и отдельный клавиатурный редактор.

## Как начать

1. Открой веб-клиент или установи приложение. Для общей библиотеки введи один персональный код на всех устройствах. При первом использовании код создаёт аккаунт. Для существующих аккаунтов доступен вход по почте.
2. Создай папку, затем тетрадь, доску или текстовый конспект. Тетради и доски поддерживают клетку, точки, линейки и чистый фон. Шаг разметки задаётся числом и сохраняется в заметке. В настройках можно выбрать белую, серую, тёплую белую, тёмно-фиолетовую, тёмно-зелёную или чёрную тему.
3. Для письма используй перо или маркер. Толщина пера задаётся дробным числом. «Текст» добавляет клавиатурную подпись на лист. Размер подписи меняется в pt, а ширина — числом или перетаскиванием правого края. Лассо выделяет штрихи для перемещения. «Выровнять фигуру» преобразует выделенные линии, прямоугольники и эллипсы. На Android «Распознать» переводит выделенные штрихи в русский или английский текст. Для первого использования языковой модели нужно подключение к сети.
4. Текстовый редактор использует Markdown и LaTeX. Команды на панели вставляют заголовки, списки, формулы, блоки кода, таблицы и ссылки на другие заметки. На Mac работают Cmd+B, Cmd+I, Cmd+1, Cmd+Shift+L и Cmd+K. Cmd+Y добавляет поле на тетради, доске или открытом вложении. Cmd+плюс и Cmd+минус меняют размер текста, Cmd+Z отменяет действие, Cmd+Shift+Z возвращает его. В других системах используется Ctrl.
5. Открой вложение внутри заметки. Для PDF выбирай страницу, для видео остановись на кадре и нажми «Пометить кадр». На открытом листе вложения работают перо и печатный текст. Лимит на один файл — 50 МиБ. Воспроизведение видео и поддержка некоторых форматов фото зависят от браузера или WebView.
6. Открывай заметки и дай вложениям загрузиться до ухода офлайн. Правки хранятся на устройстве и синхронизируются после подключения. При расхождении версий в библиотеке появляется копия с пометкой «локальная версия». Заметки, созданные до входа, остаются в локальной библиотеке устройства.

## Запуск и сборка

- **Веб**. Запусти из корня BioVision `python3 -m http.server 8080` и открой `http://127.0.0.1:8080/notes/`. GitHub Pages может отдавать эту директорию напрямую. Service Worker устанавливается на HTTPS или localhost. Браузер скачивает PDF.js и KaTeX при использовании, а установочные сборки включают их.
- **Android**. Нужны JDK 17, Android SDK 35 и Gradle 8.11.1. Из каталога `notes/` запусти `gradle -p android :app:assembleDebug`. Установочный файл находится в `android/app/build/outputs/apk/debug/app-debug.apk`.
- **macOS**. Нужны Xcode Command Line Tools. Запусти `bash scripts/build-macos.sh`. В `dist/` появится универсальное приложение для Apple Silicon и Intel в архиве. Минимальная версия macOS — 13. Сборка подписана локально.

## Обновления приложений

В версиях начиная с 0.2.0 открой настройки приложения и нажми «Проверить обновления». На Android скачай APK и подтверди обновление в системе. Для macOS распакуй архив и замени установленное приложение. Android требует тот же идентификатор пакета и тот же ключ подписи, а номер сборки должен расти. Установочные файлы лежат в бакете notes-releases по пути версии. Файл latest.json обновляют после проверки обоих пакетов.

## Supabase

Подключён выделенный проект `swszjkdnzhvnlodapqar`. В клиенте используется только публикуемый ключ. Таблица с RLS и закрытый бакет `notes-files` принадлежат приложению заметок. База проверяет владельца и ревизию при записи, файлы хранятся в префиксе владельца. Функция notes-code проверяет хеш персонального кода по закрытому списку и создаёт подтверждённый аккаунт Supabase Auth при первом входе. Администратор выдаёт новые коды, добавляя SHA-256 от случайных 16 байт, представленных 32 шестнадцатеричными символами в нижнем регистре, в notes_access_codes. Код передают владельцу отдельно.

В GitHub-интеграции Supabase рабочая папка проекта заметок — `notes`. Миграции этого проекта находятся в `notes/supabase/migrations/`. Для локального Supabase запусти `supabase start` из `notes/` и укажи локальный URL и публичный ключ в конфигурации запуска. Для проверки веб-клиента их можно задать через `localStorage.setItem('biovision-notes-cloud', JSON.stringify({url, key}))` с последующей перезагрузкой.

## Проверка на устройствах

- Galaxy S25 Ultra и Galaxy Tab S10 Lite. Проверь нажим, письмо с опорой на ладонь, ластик, лассо и распознавание обоих языков. Проверь установку и повторный запуск APK в авиарежиме.
- iPad. Проверь нажим Apple Pencil в веб-версии, касание ладонью и прокрутку тетради пальцем.
- MacBook. Открой конспект, набери формулу, таблицу и код. Проверь сочетания клавиш, прикрепление файла, повторное открытие приложения и синхронизацию с Galaxy.
