# Задание: гибриды драконов через Gemini в браузере

Для локальной сессии Claude Code на Mac владельца, с Claude in Chrome. В Chrome владелец уже вошёл в gemini.google.com (подписка Pro).

## Что сделать

Сгенерировать в Gemini тела гибридных драконов, сохранить их в репозиторий и вырезать фон. Всего 56 гибридов (21 редкий из двух стихий, 35 эпических из трёх), пять уже готовы (см. `canva-done.json`). Мифических не делать.

## Исходники

- Задания: `phagi/dragons/art-src/hybrids/canva-jobs.json`. У каждого `id` (например `water-earth`), `els` (стихии родителей по порядку) и `prompt`.
- Родители: `phagi/dragons/art-src/<стихия>/body.webp`. Gemini может не принять webp: перед загрузкой конвертировать в PNG (`python3 -c "from PIL import Image; Image.open('x.webp').save('x.png')"`).
- Пропустить уже готовые: `fire-water`, `fire-earth`, `fire-air`, `fire-flora`, `fire-light`.

## Как генерировать

1. В Gemini выбрать модель с генерацией картинок (Nano Banana / «Создать изображение»).
2. На каждое задание: новое сообщение, приложить PNG родителей в порядке `els`, вставить `prompt` из json целиком.
3. Если результат плохой (крылья появились, не профиль, одна стихия почти не видна, обрезан край), попросить переделать в том же чате, не больше двух раз. Фразы правок есть в `phagi/dragons/art-src/CHATGPT-PROMPT.md`.
4. Скачать картинку кнопкой скачивания в полном размере (не скриншот).
5. Положить в `phagi/dragons/art-src/hybrids/<id>/raw.png` (из ~/Downloads переносить сразу после скачивания, чтобы не перепутать).
6. Каждые 5–7 гибридов: коммит и push в ветку `claude/awesome-dirac-vgq6od`.

## После генерации

- Вырезать фон: `python3 phagi/dragons/dev/cutout.py <id>/raw.png <id>/body.webp` (нужен `pip install scipy`). У Gemini может быть значок-водяной знак в углу: если он остался после вырезания, удалить мелкие отдельные пятна у краёв.
- Проверить каждую `body.webp` на тёмном и зелёном фоне: чистый край, нет белой каймы и белых просветов между лапами.
- В `canva-done.json` не писать: завести `gemini-done.json` с `{id: {"file": "<id>/body.webp", "tries": n, "note": "..."}}`.
- Если Gemini упрётся в дневной лимит, остановиться, записать в `gemini-done.json`, на каком задании остановились, и закоммитить.

## Также

Скачать из Canva (canva.com → Проекты → Загрузки) в полном размере четыре готовых гибрида по именам из `canva-done.json` (`fire-earth`, `fire-air`, `fire-flora`, `fire-light`) и положить так же в `<id>/raw.png`. `fire-water` у владельца уже есть: взять файл `AaGb4QruiRtQl4hxZ1dDpw-AaGb4QruJKrRLR4W_C2Eqw.jpg` из Canva тем же способом.

## Нельзя

- Не менять код игры, только папку `art-src/hybrids/` и коммиты с картинками.
- Не трогать другие вкладки и аккаунты в браузере, не вводить пароли.
