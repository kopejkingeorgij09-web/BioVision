# Трек к ШАДу

Личный трекер подготовки к ШАД: 66 вебов Профиматики (матан 1 и 2 семестр, графики, интегралы) по датам с октября 2026 по апрель 2027, у каждого веба слот на просмотр и слот на ДЗ, отметка по пяти стадиям и заметка.

Адрес: https://kopejkingeorgij09-web.github.io/BioVision/shad/

## Файлы

- `plan.json` — весь план: вебы, даты, время, курсы, часы, перерыв на сессию. **Чтобы поменять расписание, правь только этот файл.** Одна строка = один веб.
- `app.js` — логика: стадии, отрисовка недель, фильтры, лист отметки, сохранение.
- `style.css` — оформление (светлая и тёмная тема через переменные в `:root`).
- `index.html` — разметка страницы.

## Как устроен план

```json
{"n": 5, "course": "m1", "code": "Лекция 3", "title": "Определение предела последовательности",
 "web": {"date": "2026-11-12"}, "hw": {"date": "2026-11-14"}}
```

- `n` — номер по порядку (1, 2, 3… без пропусков; по нему хранятся отметки, поэтому номера уже пройденных вебов не меняй);
- `course` — ключ из `courses` (`m1`, `gr`, `in`, `m2`); новый курс добавь в `courses` и цвет `--<ключ>` в `style.css`;
- `code` — как веб называется в приложении Профиматики: «Лекция 3» и «Семинар 2» в модулях матана, «Веб 4» в графиках, «Азы 1/3» в интегралах;
- `web.date` — день просмотра веба, `hw.date` — дедлайн ДЗ. Время необязательно: можно добавить `"from": "14:15", "to": "18:00"`, тогда трекер покажет и его;
- сейчас ритм такой: вебы по вторникам, четвергам и субботам, ДЗ до конца второго дня после веба, с 21 декабря по 24 января пауза на сессию.

Примеры правок, которые можно поручить Claude или ChatGPT:
- «сдвинь все вебы после 1 декабря на неделю вперёд»;
- «добавь в конец блок линейной алгебры, 18 вебов, по три в неделю»;
- «дедлайн ДЗ не через два дня, а через три».

## Отметки

Хранятся в Supabase (коллекция `shad`, проект `bioviz`), читать и писать их может только учитель: на странице «Войти» → код учителя. Без входа отметки сохраняются только в этом браузере, а после входа переносятся в облако.
