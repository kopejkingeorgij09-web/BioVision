# Личное чтение и письменные работы

В библиотеке БиоВиза доступны личный код, стопка ошибок, темп чтения и письменные работы. Вводные рекламные фразы убраны; объяснение локального хранения PDF свёрнуто.

## Синхронизация

Код придумывается пользователем один раз (12–128 символов, регистр учитывается). Можно создать случайный код из 96 бит случайности, скопировать его в настройках и войти на другом устройстве. Создание и вход — отдельные действия: опечатка при входе не создаёт новый профиль. Код не связан с правами ученика/руководителя. На сервере хранится SHA-256 с отдельным пространством имён; код даёт доступ к персональному профилю. Секрет не помещается в URL и журнал приложения.

Синхронизируются место чтения, закладки, настройки читалки, ответы, черновики, ошибки, баллы, письменные работы и статистика чтения. PDF остаются в IndexedDB устройства; для другого устройства добавляется тот же файл. SHA-256 файла даёт стабильный идентификатор; при открытии старого PDF регистрируется соответствие его прежнему идентификатору. Бинарные файлы в облако не отправляются.

Каждая запись имеет серверную ревизию и локальный флаг неотправленного изменения. Очередь сохраняется до сетевого запроса; повторный запуск и отсутствие сети её не стирают. Сервер сериализует изменения одного владельца и сравнивает ожидаемую ревизию. При конфликте сохраняется отдельная облачная копия обеих версий; пользователь выбирает нужную в «Личном коде». Удаление — синхронизируемая запись с null. Переключение профиля не импортирует данные другого профиля. Перенос гостевых данных предлагается отдельно при подключении; старые ключи не удаляются.

`bv_personal` — закрытая схема, без USAGE и прав на таблицы у anon/authenticated, с включённым RLS без разрешающих политик. Единственная публичная RPC `bv_personal_sync` использует capability-код для авторизации, фиксированный пустой search_path и явные имена схем. Она намеренно SECURITY DEFINER: прямого доступа к таблицам нет. Сведения [advisors об RPC](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable) и [RLS без политик](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy) соответствуют этому устройству доступа. Ограничены размер пачки, размер записи, объём профиля (32 MiB), количество записей и число запросов/неудачных попыток с IP. Существующие таблицы и права БиоВиза/Фагов не меняются.

## Ошибки и самооценка

Неверный ответ сохраняет дату первой/последней ошибки и число ошибок. Правильное повторное решение снимает задание с активной стопки, сохраняя историю. Старые ответы `ok:false` также попадают в стопку. Черновик записывается при вводе без отложенного таймера, чтобы последний текст не терялся при переходе.

У письменных заданий книги три явно описанных критерия самооценки (по 0–2), общий балл и сохранение ответа. Это ориентиры самооценки, а не официальные критерии олимпиад и не автоматическая оценка. Неполный результат возвращает задание в стопку. Для собственных письменных работ создаются произвольные критерии с максимумами 1–100, выставляются баллы, считается сумма; сохраняется текст ответа. Работу и отдельный критерий можно удалить.

## Темп

Активное время отсчитывается при открытой читалке в видимой вкладке; после 90 секунд без взаимодействия счёт останавливается. При переходе с PDF-страницы с не менее чем 20 секундами чтения она отмечается как прочитанная. Перескок через страницы не засчитывает пропущенные. Уникальные страницы объединяются между устройствами; повторное чтение не даёт новых страниц.

Прогноз использует новые страницы за последние 14 календарных дней и продолжительность этого окна с первого наблюдения, включая дни без чтения. Скорость — страницы на активный час; срок — оставшиеся страницы, делённые на страницы за календарный день. До трёх новых страниц и минуты активного времени числа дней нет; до трёх дней наблюдений прогноз обозначен предварительным. Временная шкала использует локальные календарные даты. Это приближение: открытая страница и взаимодействие не доказывают понимание или прочтение каждого слова.

## Проверки

- `tools/check_personal_learning.py`: компактная библиотека, стопка/повторное решение, баллы и черновики, собственная работа, перезагрузка, мобильная тёмная тема.
- `tools/check_reading_forecast.py`: скорость, дни без чтения, дубликаты устройств, перечитывание, недостаток данных и порог времени; три ширины и обе темы.
- `tools/check_alberts_practice.py`: все 600 карточек и прежние черновики, ссылки, выдача/фильтры, 3:1 в каждой теме.
- Дополнительно проверены два независимых браузера против реальной RPC: офлайн-перезагрузка, повторная отправка, черновики/закладки, конфликт и облачная копия, изоляция профилей. Созданные тестовые профили удалены.
- SQL проверки выполнены с ролью anon в транзакции с rollback: закрытый доступ к схеме, создание, запись, конфликт ревизии, отказ неверному коду. Advisors проверены.
- Посимвольная проверка DOM всех 401 пунктов оглавления подтверждает, что текст и иллюстрации книги не изменились.
