# Проверки исправлений ревью БиоВиза

Область: основной курс, лабораторные, читалка и общий облачный адаптер.
Материалы учебника и отдельные приложения репозитория не изменяются.

Изменения:

- Сервер скрывает черновики и их фотографии от гостей и участников.
- Прогресс разделён по профилям. Сначала читается облако; сервер атомарно объединяет
  отметки даже от старого клиента. Смена профиля отменяет ожидающую синхронизацию.
  Старые отметки без владельца сохранены; участник может добавить их через профиль.
- Резервная копия скачивается только после успешного чтения всех разделов и фото.
- Уход из редактора требует подтверждения при изменении текста, флажков и фотографий.
  Во время сохранения или подготовки фото уход блокируется до завершения операции.
- При добавлении PDF сохраняются движок, worker, шрифты и CMap, а также оболочка сайта.
  Неудачная подготовка явно показывается, сам PDF остаётся в библиотеке.
- Готовность офлайн-копии требует каждого файла; отсутствующие файлы скачиваются повторно.
- Загрузчик и кнопка восстановления видны до и после создания теневого DOM.

## Браузер

Нужны Python, Playwright и Chromium. Облачные запросы полностью подменены тестовыми.

```sh
python3 -m http.server 8010 --bind 127.0.0.1
python tools/check_review_fixes.py --url http://127.0.0.1:8010/
```

Проверки: чистое и общее устройство, смена профиля во время чтения облака,
редактор, шесть вариантов отказа резервного копирования, повторное сохранение
неполного кеша, первая загрузка PDF.js после перезагрузки без интернета,
телефон 390 px, планшет 820 px и десктоп 1280 px в обеих темах, ошибка запуска и восстановление.
Для отдельной группы: `--only progress editor backups offline smoke`.

## PostgreSQL

Используется отдельная локальная Docker-база. В SQL-файле только вымышленные коды.
После применения основной миграции `20261025_bioviz_core.sql` и миграции
`bioviz_review_fixes` выполните:

```sh
docker exec -i CONTAINER psql -U postgres -v ON_ERROR_STOP=1 < tools/check_review_fixes.sql
python3 tools/check_review_concurrency.py CONTAINER
```

SQL проверяет чтение черновиков и фото, публикацию и снятие с публикации,
права вызова RPC и объединение прогресса. Тест конкурентной записи проверяет
24 одновременных обновления, включая создание нового документа.

## Учебник

```sh
python3 tools/verify_reading.py
python tools/check_reading_dom.py
```

DOM-проверка использует сервер на порту 8000. Она сравнивает все 401 пункта
содержания с исходными данными. Проверка целостности учитывает 796 страниц,
27 680 строк текстового слоя и 833 изображения.
