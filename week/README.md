# Неделя

Публичный планер задач для подписчиков владельца. Адрес: https://kopejkingeorgij09-web.github.io/BioVision/week/

Это копия планера из «Зова леса» (`bamboo/`) без ШАДа, привычек, опыта, леса, дневника и облака. Внутри неделя, месяц, «Когда-нибудь», календари по темам, повторы, напоминания, перетаскивание, все пять тем («Бумага», «Тёмная», «Ночной лес», «Лесной день», «Как в системе») и клавиши (список по «?»).

## Данные

Задачи хранятся только в браузере пользователя: ключи `week-docs`, `week-dirty`, `week-planner`, `week-theme` и другие с приставкой `week-`. С данными «Зова леса» (`bamboo-…`) они не пересекаются, хотя оба сайта лежат на одном домене. Сервис-воркер чистит только свои кеши `nedelya-…`. В настройках есть резервная копия файлом (`app: 'week'`).

## Связь с «Зовом леса»

Код скопирован из `bamboo/js` (core, ui, tasks, keys, search, app) и стили целиком. Отличия: `B.connect` без облака, свой `seed()` с календарями Входящие, Учёба, Работа, Личное, опыт обнулён (`B.XP`), нет вида ШАД (вместо блока «ШАД на неделю» блок «Дела на неделю»: задачи без дня с полем `wk` = понедельник, ключ списка `w:<дата>`, видны и в колонке «Неделя» месяца), меню из трёх пунктов, свои настройки. Улучшения планера в `bamboo/` сюда сами не попадают, их надо переносить руками.

## Синхронизация по коду

Отдельный бесплатный проект Supabase `nedelya` (не bioviz). Схема и функции в `week/sync.sql` (выполнены 04.11.2026 через SQL Editor). Таблица `wk_docs` (owner = sha256 от кода, id, data, at), таблицы закрыты RLS без политик, доступ только через функции `wk_check`, `wk_pull`, `wk_push`. Код от 8 до 128 символов, 20 промахов `wk_check` в час с одного адреса, 200 КБ на запись, 5000 записей на код. Вложения `f_…` не синхронизируются.

В браузере: `week/js/core.js`, блок «синхронизация по коду». Код и отметка времени в `week-code`, `week-since`. Изменения уходят через тот же механизм «грязных» записей, что и в «Зове леса», новые с сервера подтягиваются раз в 30 с и при возврате во вкладку. При входе с существующим кодом облако главнее, локальные задачи добавляются.

После правок подними `?v=` у изменённых файлов в `week/index.html`.
